## 📐 Estructura de Secciones

1. **Header Sticky**: Identidad visual con logotipo oficial, navegación interactiva (`Inicio`, `Nosotros`, `Soluciones`, `Tecnología`, `Contacto`), botón destacado `Contactarnos` y menú lateral responsive para dispositivos móviles.
2. **Hero**: Título `Logitec`, subtítulo `Tecnología que impulsa tu negocio`, descripción institucional, badges de verificación legal (NIT 900805654-7, Cali, Colombia) y composición tecnológica con visual oficial corporativo.
3. **Sobre Logitec (Nosotros)**: Declaración institucional verídica y tarjeta de credenciales legales corporativas con datos oficiales.
4. **Valores**: 4 pilares fundamentales (`Innovación`, `Tecnología`, `Confianza`, `Compromiso`) con iconos minimalistas y descripciones profesionales.
5. **Soluciones para tu empresa**: 4 líneas conceptuales (`Soluciones Tecnológicas`, `Optimización`, `Innovación Digital`, `Soporte y Acompañamiento`) con ventanas modales interactivas para consulta.
6. **Tecnología para avanzar**: Visualización tecnológica abstracta interactiva en HTML5 Canvas con topología de nodos, líneas de datos y componentes de arquitectura digital (sin logos de terceros).
7. **¿Por qué elegir a Logitec?**: 4 bloques estructurados (`01 Enfoque profesional`, `02 Visión tecnológica`, `03 Atención cercana`, `04 Orientación a resultados`).
8. **Call to Action (CTA)**: `Conversemos sobre tu próximo proyecto` con enlaces directos a `mailto:logitec@logitec.store`, `tel:+573044019906` y botón directo a WhatsApp.
9. **Contacto**: Información corporativa verificada con copiado rápido de NIT/Dirección/Teléfono/Correo, mapa de ubicación en Cali y formulario con validación client-side y feedback visual.
10. **Footer**: Nombre legal `LOGITEC` y `NIT 900805654-7` en texto real accesible, enlaces legales de Habeas Data (Ley 1581 de 2012) y Términos de Uso, y copyright 2026.
11. **Acciones Flotantes**: Botón flotante de WhatsApp, llamada directa y botón interactivo de retorno al inicio (*Scroll to top*).

## 🛠️ Comandos de Desarrollo y Producción

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción (TypeScript + Vite)
npm run build

# Previsualizar build de producción localmente
npm run preview
```
